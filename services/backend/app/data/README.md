# Каталог для офлайн-демо

Сид создаётся существующим пайплайном `data/generators/run_all.py` и загружается командой
`make seed`. Он содержит 61 направление, 1 318 отелей (не менее 40 в десяти направлениях),
45 284 ставок за ночь на 2026-11-01…2026-12-07, 3 788 плеч перелётов и 1 282 трансфера.
Ночь без строки в `stay_rates` означает неизвестную доступность, а не нулевую цену.
В каталоге есть ночные рейсы и прилёты позже 18:00 при дедлайне заселения 14:00–16:00.

Каждая строка каталога с `source_id` несёт `fetched_at` и `synthetic`. Значение
`synthetic=true` ставится только сгенерированным строкам; полученные из GeoNames,
OurAirports, Open-Meteo и OSRM наблюдения остаются `synthetic=false`. Цены отелей,
ставок и перелётов — синтетические. Дата источника закреплена за неизменным сидом:
повторный запуск с теми же исходными данными сохраняет байты JSON.

Для приёмки: `make up && make seed && make test`. Проверка двух прогонов генератора
проводится на копии `data/seeds`, чтобы не менять рабочий каталог; регрессионный тест
расположен в `tests/scenarios/test_seed_sources.py`.
